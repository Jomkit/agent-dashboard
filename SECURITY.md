# Security Policy

## Supported Versions

The following versions of Agent Dashboard currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not open a public issue.**
2. Report the vulnerability privately using [GitHub Private Vulnerability Reporting](https://github.com/Jomkit/agent-dashboard/security/advisories/new) or contact the maintainer directly.
3. Include detailed steps to reproduce the issue and any relevant logs or sample payloads.

We take security seriously and will investigate and respond to valid reports promptly.
